General Information

ColorBlast is committed to protecting the privacy of its users.

Data Collected

  • Game scores and statistics
  • Leaderboard data
  • Preferred language settings

Firebase Usage

Leaderboard data is stored in Firebase Cloud Firestore. It is not shared with third parties.

Third-Party Services

  • Firebase Cloud Firestore — storing leaderboard data
  • Firebase Authentication — anonymous user identifier (no personal information)
  • Firebase Crashlytics — crash diagnostics (error reports only; no personal data)
  • Firebase Analytics — anonymous usage statistics

No advertisements are shown, and no personal data is shared with third parties.

Children's Privacy

No personal data is knowingly collected from children under 13.

User Rights

  • Request access to your data
  • Request deletion of your data

For a deletion request, see the Account and Data Deletion page.
